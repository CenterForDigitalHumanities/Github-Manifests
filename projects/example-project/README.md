# example-project

This project is generated by repository scripts.

## Inputs
- Add local images in images/
- Add external references using .lnk files in images/ (one HTTP(S) URL per file)
- Optional advanced configuration in info.yml

## Generated Outputs
- manifest.json
- WARNING.md

## Links
- Manifest: ./manifest.json
- Images folder: ./images/
- Mirador (replace MANIFEST_URL): https://projectmirador.org/embed/?iiif-content=MANIFEST_URL
- Universal Viewer (replace MANIFEST_URL): https://uv-v3.netlify.app/#?manifest=MANIFEST_URL

## TPEN3
Use the generated manifest URL in TPEN3 when creating a new transcription project.

> This file is regenerated when manifest generation runs. Put durable custom metadata in info.yml.
